`schemastud-message-ratchet` scanner 3 also counts the string default of a parameter or destructured binding whose name reaches a display sink, in its own function or passed by name one hop into a component of the same file (`navLabel = 'Account'` rendered as `label={navLabel}`). The children of a `<style>` or `<script>` element are never counted. The `unscanned` list gains a default passed more than one hop or to a component in another file. A baseline measured by scanner 2 fails with "scanner widened: re-measure with --write" until it is re-measured.
