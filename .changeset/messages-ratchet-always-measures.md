`schemastud-message-ratchet` never passes without measuring (frame-foundation 79). **The bin always runs:** the census moved to a side-effect-free module, `bin/ratchet-lib.mjs`, which `@schemastud/messages/ratchet` now exports; the bin is a thin entry that calls `runRatchet` unconditionally, with no entry-point guard, so a pnpm shell shim, an npm `.bin` link, a wrapper or a loader can no longer turn the gate into a silent exit 0. The bin name and the package exports are unchanged. **No silent pass:** a config with no packages, or with a package whose roots hold no source file the census reads (only excluded, `.d.ts` or non-source files), fails with `Nothing measured`, naming the config and every such package; before, such a package counted 0 and passed. CONFORM: a host that imports the census from the bin file imports `@schemastud/messages/ratchet` instead (importing the bin now runs the gate); a host config with an unreadable package now fails, and the fix is to point the package at its real sources or remove it from the config and the baseline together. This repo's own config dropped `@schemastud/_resources` (`_resources/types` holds only a `.d.ts`) from the config and the baseline for that reason.
